🟣 KOYEB DEPLOYMENT

1. Fork the official TEDDY-XMD repository.
2. Open "Koyeb" (https://app.koyeb.com/).
3. Create a new application.
4. Connect your GitHub repository.
5. Configure the deployment using the repository's "koyeb.yaml" and "Dockerfile".
6. Add your "SESSION_ID" environment variable.
7. Deploy your bot.

Required environment variable:

Variable| Description
"SESSION_ID"| Your "TEDDY-XMD~..." WhatsApp session

«Note: Koyeb deployment requires a valid Dockerfile and compatible "koyeb.yaml" configuration.»

🟣 RENDER DEPLOYMENT

1. Fork the official repository.
2. Open "Render" (https://render.com/).
3. Create a new Web Service.
4. Connect your GitHub repository.
5. Render will detect "render.yaml".
6. Configure your "SESSION_ID".
7. Deploy.

🟣 HEROKU DEPLOYMENT

1. Fork the official repository.
2. Open the Heroku deployment link above.
3. Configure your application.
4. Add your "SESSION_ID".
5. Deploy your bot.

«Note: Hosting providers may require additional configuration depending on their deployment requirements.»
