## About

**TEDDY-XMD-ULTRA** is a WhatsApp automation project powered by Teddy Tech.

## Deployment

- Node.js **20.x** is required.
- Set `SESSION_ID` in your hosting provider's environment/config vars.
- Start command: `npm start`.
- The application requires outbound HTTPS access during startup.

## Environment variables

| Variable | Purpose |
|---|---|
| `SESSION_ID` | WhatsApp session string |
| `DEBUG` | Optional debug flag |

## Project

Source code and project updates: [TEDDY-XMD](https://github.com/Teddyxmd/TEDDY-XMD)
